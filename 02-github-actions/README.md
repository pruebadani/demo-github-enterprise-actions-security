# GitHub Actions

Esta carpeta contiene workflows listos para mostrar en la demo.

Para que GitHub los ejecute, copiar los archivos de `workflows` a:

```text
.github/workflows/
```

## Orden recomendado para mostrar

1. `ci-pr-validation.yml`: valida cada Pull Request.
2. `deploy-pages.yml`: publica el sitio en GitHub Pages.
3. `dependency-review.yml`: bloquea dependencias riesgosas en PR.
