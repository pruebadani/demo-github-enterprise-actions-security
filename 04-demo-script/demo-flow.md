# Demo flow

## Demo de 15 minutos

1. Presentar el repositorio y el objetivo empresarial.
2. Mostrar la app en `01-app-github-pages`.
3. Usar Copilot para pedir una mejora simple.
4. Abrir un Pull Request.
5. Mostrar Actions corriendo validaciones.
6. Mostrar GHAS como capa de seguridad integrada.
7. Mergear y mostrar despliegue a GitHub Pages.

## Mensaje de cierre

GitHub Enterprise permite acelerar desarrollo con Copilot, automatizar entrega con Actions y sumar seguridad con GHAS sin sacar al equipo de su flujo natural.
