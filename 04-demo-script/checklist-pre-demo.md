- Repositorio creado en GitHub.
- GitHub Pages habilitado desde GitHub Actions.
- Workflows copiados a `.github/workflows`.
- Branch protection configurado para `main`.

- CodeQL ejecutado al menos una vez.

- Demo probada con una rama feature y Pull Request.
