# GitHub Advanced Security

Material para mostrar controles de seguridad en GitHub Enterprise.

## Puntos de demo

| Capacidad | Que mostrar |
| --- | --- |
| CodeQL | Analisis semantico del codigo y alertas de seguridad. |
| Secret scanning | Deteccion de secretos antes de que lleguen a produccion. |
| Dependabot | Alertas y PRs automaticos para dependencias vulnerables. |
| Dependency review | Bloqueo de dependencias riesgosas en Pull Requests. |

## Notas

Los archivos de ejemplo estan separados para evitar insertar secretos reales o vulnerabilidades innecesarias en el sitio principal.
